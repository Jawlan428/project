================================================================================
                              HOW THE SYSTEM WORKS
================================================================================

STARTUP SEQUENCE:
  1. Scene loads → AnalyticsCanvas starts
  2. Subscribe to AuditLogger.OnAuditEvent
  3. Scan directories for audit_*.json files
  4. Load all historical events from files
  5. Load in-memory events from current session
  6. Display all events on UI canvas
  7. Listen for new events and update UI in real-time

DIRECTORIES SCANNED (in priority order):
  1. YourProject/QuestRecordings/AuditLogs/
  2. Desktop/YourProjectName_AuditLogs/
  3. AppData/LocalLow/.../AuditLogs/

FILE FORMAT:
  - audit_[sessionId]_[timestamp].json
  - Contains array of AuditEvent objects

EVENT FLOW:
  Game Action → AuditLogger.Log() → OnAuditEvent triggered 
  → AnalyticsCanvas updates → UI displays event → Saved to JSON on quit

================================================================================
                           INTEGRATION EXAMPLES
================================================================================

LOG AN EVENT IN YOUR SCRIPTS:

  // Simple event
  AuditLogger.Instance.Log(AuditEventType.JOIN_MEETING);

  // Event with details
  AuditLogger.Instance.Log(
      AuditEventType.APPLE_PICKED,
      targetId: "Red Apple",
      zoneName: "Orchard",
      position: transform.position
  );

  // Event with metadata
  AuditLogger.Instance.Log(
      AuditEventType.POLL_VOTE,
      targetId: "Option A",
      metaJson: "{\"question\":\"Your question?\",\"vote\":\"A\"}"
  );

================================================================================
                              TROUBLESHOOTING
================================================================================

NO EVENTS APPEAR:
  → Check Console for "[AnalyticsCanvas]" messages
  → Verify Content Panel is assigned in Inspector
  → Ensure AuditLogger exists (appears in Hierarchy when playing)

"CONTENT PANEL NOT ASSIGNED" ERROR:
  → Select AnalyticsCanvas in Hierarchy
  → Find Content Panel in your UI hierarchy
  → Drag it to "Content Panel" field in Inspector

EVENTS NOT LOADING FROM FILES:
  → Check if audit log files exist in directories
  → Look for Console message: "Found X audit log files"
  → Files must match pattern: audit_*.json

PLAYER NAME SHOWS "UNKNOWN":
  → Set player name before logging:
     PlayerIdentity.Instance.SetPlayerName("YourName");
