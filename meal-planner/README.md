# 🍽️ מתכנן הארוחות השבועי

אפליקציית ווב פשוטה (עמוד אחד) לתכנון ארוחות שבועי בעברית. עובדת גם ללא אינטרנט ושומרת את כל הנתונים במכשיר שלך בלבד (localStorage).

## איך מריצים
פותחים את הקובץ `index.html` בדפדפן — זהו. אין צורך בהתקנה או בשרת.
אפשר גם להוסיף למסך הבית בטלפון (Add to Home Screen) ולהשתמש כמו אפליקציה.

## מה יש בפנים
- **🥕 המזווה** — רשימת המצרכים שקיימים אצלך בבית כרגע.
- **🍳 מה להכין** — לפי המזווה, המערכת ממליצה מה אפשר לבשל *עכשיו*, מה *כמעט מוכן* (חסרים 1–3 מצרכים), ומה דורש קנייה.
- **📅 תכנון שבועי** — שיבוץ ארוחות (בוקר / צהריים / ערב) לכל ימי השבוע.
- **🛒 רשימת קניות** — נבנית אוטומטית מהתכנון השבועי, פחות מה שכבר יש במזווה. אפשר לסמן פריטים שקנית ולהעביר אותם ישר למזווה.
- **📖 מאגר מתכונים** — כל הארוחות שהכנת נשמרות עם מצרכים והוראות, לשחזור בכל עת. אפשר לסמן "הכנתי" כדי לעקוב אחרי ארוחות מועדפות.

## גיבוי ושחזור
בעמוד הבית יש כפתורי **גיבוי נתונים** (הורדת קובץ JSON) ו**שחזור מגיבוי**, כדי להעביר נתונים בין מכשירים או לשמור עותק.

## הערות
- התאמת מצרכים היא חכמה־למחצה: מתעלמת מכמויות ויחידות ("3 ביצים" = "ביצים") ומתאימה גם התאמות חלקיות.
- אפשר להגדיר במתכון מצרכי בסיס (מלח, שמן, מים) שלא נכללים בחישוב החוסרים.
- המערכת מגיעה עם כמה מתכונים לדוגמה — אפשר לערוך או למחוק אותם בחופשיות.
